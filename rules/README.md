# Правила для `.claude/rules/`

Правила, которые агент подгружает сам при каждом старте. Кладутся в `.claude/rules/` рабочего каталога.
К статье [Claude Code + EDT на БП КОРП](https://infostart.ru/1c/articles/2815822/) (UPD 28.10.2026, по просьбе из комментариев).

## Как использовать

1. Скопировать нужные файлы в `.claude/rules/` своего проекта.
2. Заменить `Преф_` на свои префиксы, имена общих модулей и расширений тоже на свои.
3. Дописывать правило после каждой аварии, по [шаблону](../templates/rule-template.md): симптом, причина, рецепт, ложные направления, проверка.
