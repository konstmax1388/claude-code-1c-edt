# Вёрстка управляемых форм: грабли, которые из кода не видно

Правило появилось 2026-09-19 после четырёх итераций с «таблица не на всю ширину» в рабочем месте «Полив за день».
Рендер формы из EDT недоступен (`get_form_screenshot` требует флаг `-DnativeFormBufferedLayoutRender=true`), поэтому
результат вёрстки виден только пользователю — каждый промах стоит обновления базы и скриншота.

Применяется: при генерации форм скриптом (свой генератор формы), при правке `Form.form` мимо конструктора, при разборе жалоб
«элемент не растягивается / уехал вправо».

---

## ★ Необъединённая группа (`united=false`) делает свои поля колонками родителя

Горизонтальная **необъединённая** группа (`<united>false</united>`, `Объединённая = Ложь`) — не «коробка», а строка сетки
родительской группы: каждый её элемент становится **колонкой** формы. Всё, что стоит ниже в вертикальном родителе
(инструкция, таблица, итог), попадает в **первую колонку** и получает её ширину — ширину поля «День полива». Внешне:
таблица и декорация одинаково узкие с горизонтальной прокруткой, поля шапки разъехались по ширине окна, при расширении
поля шапки таблица ещё сужается.

Это штатное назначение необъединённых групп — выравнивать поля нескольких строк по общим колонкам; для шапки над таблицей
оно не подходит. Шапка над таблицей — **всегда объединённая** горизонтальная группа (`<united>true</united>`), как в
`Преф_НарядыПоСборуУрожая`.

Ложные направления, на которые ушли итерации: `АвтоМаксимальнаяШирина` таблицы, `РастягиватьПоГоризонтали` полей,
пользовательские настройки формы (проверять `ХранилищеНастроекДанныхФорм.Выбрать(...)` — их не было), `Ширина = 0`.
Ни одно не влияет, пока группа необъединённая.

EDT в `Form.form` **опускает** `<united>` при значении по умолчанию, так что в файле необъединённость может быть незаметна:
искать группу без тега `<united>` — это и есть `false`. Генератор форм должен писать `united=true` всегда.

## Переносы строк в заголовке декорации

`\n` в `<value>` заголовка декорации в базу не доезжают — текст склеивается в одну строку. Многострочную инструкцию
собирать в `ПриСозданииНаСервере`: `Элементы.Инструкция.Заголовок = СтрСоединить(СтрРазделить(Текст, "|"), Символы.ПС)`.

## `СвязьПараметровВыбора` на сервере формы не определён (8.5)

`Новый СвязьПараметровВыбора(...)` в `ПриСозданииНаСервере` падает «Тип не определен». Связь «клетка по саду» задавать
в XML: в `extInfo` поля `<choiceParameterLinks><name>Отбор.Владелец</name><datapath>…<segments>Items.Таблица.CurrentData.Сад</segments>…`.

## У коллекции формы нет `ВыгрузитьКолонку`

`ДанныеФормыКоллекция` (реквизит-таблица формы на сервере) — не `ТаблицаЗначений`: колонку собирать циклом либо
`РеквизитФормыВЗначение`.

## Один обработчик — один элемент

Стандарт EDT `form-items-single-event-handler`: один и тот же обработчик у нескольких элементов — предупреждение MAJOR.
Делать по обработчику на элемент, внутри — вызов общей процедуры.
