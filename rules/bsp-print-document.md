# БСП-печать документа конфигурации (не внешняя обработка)

Правило добавления рабочей печатной формы встроенному документу/справочнику конфигурации на БСП (БП КОРП и внедрённые блоки `Преф_`).

Применяется: при добавлении печати объекту метаданных **самой конфигурации** (через модуль менеджера + макет). Для печати из **внешней обработки** (СведенияОВнешнейОбработке) — другой механизм, см. навык `1c-bsp-registration` из набора Desko77.

Дополняет `bsl-ssl.md` (работа с БСП) и `edt-bsl-write-safety.md` (запись BSL).

---

## Главное правило: без регистрации в манифесте печати кнопки НЕТ

Наличие в модуле менеджера процедур `ПриОпределенииНастроекПечати` / `ДобавитьКомандыПечати` / `Печать` — **недостаточно**. БСП вызывает `ДобавитьКомандыПечати` объекта, **только если объект зарегистрирован в манифесте печати**.

Проверено (`CommonModule.УправлениеПечатью`): `КомандыПечатиОбъекта` → `НастройкиПечатиОбъекта(Менеджер).ПриДобавленииКомандПечати` → и лишь тогда `Менеджер.ДобавитьКомандыПечати(...)`. Манифест собирается из переопределяемых процедур (см. ниже). Объекта нет в манифесте → методы печати не вызываются → в форме (и в «Ещё») печати нет.

**Симптом пропущенной регистрации:** менеджер-модуль корректен, EDT-валидация чистая, БД обновлена, сеанс перезапущен — а кнопки «Печать» нет ни в списке, ни в документе, ни в «Ещё». Это НЕ синхронизация EDT — это отсутствие п.3 ниже.

## Обязательные 4 части (нужны все)

### 1. Модуль менеджера объекта — регион `#Область БСП`

```bsl
Процедура ПриОпределенииНастроекПечати(Настройки) Экспорт
	Настройки.ПриДобавленииКомандПечати = Истина;
КонецПроцедуры

Процедура ДобавитьКомандыПечати(КомандыПечати) Экспорт
	КомандаПечати = КомандыПечати.Добавить();
	КомандаПечати.Идентификатор = "Преф_ИдПФ";
	КомандаПечати.Представление = НСтр("ru = 'Печать'");
	КомандаПечати.Обработчик    = "УправлениеПечатьюБПКлиент.ВыполнитьКомандуПечати"; // в БП именно этот
	КомандаПечати.Порядок       = 100;
КонецПроцедуры

Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода) Экспорт
	Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, "Преф_ИдПФ") Тогда
		УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(
			КоллекцияПечатныхФорм, "Преф_ИдПФ", НСтр("ru = 'Заголовок ПФ'"),
			СформироватьПечатнуюФорму(МассивОбъектов), , "Документ.ИмяДокумента.Печать");
	КонецЕсли;
	ОбщегоНазначенияБП.ЗаполнитьДополнительныеПараметрыПечати(
		МассивОбъектов, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода);
КонецПроцедуры
```

`Обработчик` печатной формы (5-параметровая `Печать`) — сигнатура строго `(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода)`.

### 2. Макет печатной формы

`Templates/Печать/Template.mxlx` (области Шапка / ЗаголовокТаблицы / СтрокаТаблицы / Подпись). Вёрстку (ширины колонок, границы) править в конструкторе макета, не в XML (см. CLAUDE.md, п.3 про `.mxlx`).

### 3. ★ РЕГИСТРАЦИЯ В МАНИФЕСТЕ — то, что забывается

В `CommonModule.УправлениеПечатьюПереопределяемый`, процедура `ПриОпределенииОбъектовСКомандамиПечати(СписокОбъектов)` — добавить строку с маркерами модификации:

```bsl
	// <<Преф
	СписокОбъектов.Добавить(Документы.ИмяДокумента);
	// >>Преф
```

Это штатная точка расширения БСП (переопределяемый модуль — он ровно для добавления своих объектов). Там же зарегистрирован рабочий типовой `АвансовыйОтчет`. Достаточно `ДобавитьКомандыПечати` в менеджере (современный `ПриОпределенииНастроекПечати` — опционально, в этом пути не вызывается).

### 4. Форма и объект

- Форма документа использует `ПодключаемыеКоманды` (у стандартных форм документа уже есть: `ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект)` + диспетчеры `Подключаемый_*`).
- У объекта `useStandardCommands = true`.

## Деплой и проверка

1. `write_module_source` (менеджер-модуль объекта + переопределяемый модуль) — идёт через EDT.
2. `revalidate_objects` по обоим модулям.
3. Обновить конфигурацию базы данных.
4. **Перезапустить сеанс 1С** — манифест печати кешируется (`УправлениеПечатьюПовтИсп`) на сеанс, формы кешируются в сессии.
5. Проверить: в списке и в документе появилась кнопка/подменю «Печать».
