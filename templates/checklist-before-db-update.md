# Перед «Обновить конфигурацию базы данных»

Чеклист, который агент проходит сам и показывает человеку результат.

| # | Проверка | Как | Норма |
|---|---|---|---|
| 1 | Сборка EDT закончилась | статус-бар, ответ MCP без «Project is building», CPU процесса EDT упал | нет сборки |
| 2 | Ошибки проекта по своим объектам | `revalidate_objects` + `get_project_errors` по списку объектов | прироста нет |
| 3 | Новые объекты есть в составе | объект в `Configuration.mdo` и в подсистеме | все на месте |
| 4 | Роли | `python check_rights_order.py <src> <роли>` | 0 замечаний |
| 5 | Схемы СКД, правленные скриптом | `python check_dcs_nodes.py <отчет>` + компоновка схемы из файла | 0 замечаний, варианты компонуются |
| 6 | Вызовы функций с измененной сигнатурой | поиск вызовов, сверка числа аргументов | совпадает (EDT это не ловит) |
| 7 | Чужие правки в пакете | `git status`: не своих изменений нет или о них знают | понятен состав |
| 8 | Бэкап базы, если меняется структура | новый регистр, реквизит, документ | бэкап свежий |
| 9 | База свободна | нет процесса `1cv8.exe DESIGNER` на эту базу, кроме агента EDT | свободна |

После обновления: перезапустить сеанс (кешируется командный интерфейс и манифест печати),
для новых вариантов отчетов БСП запустить обновление ИБ (`/CЗапуститьОбновлениеИнформационнойБазы`).

Если обновление висит без ошибки:

1. Есть ли в пакете `Roles/*/Ext/Rights.xml`? Убрать роли из пакета и повторить. Прошло за минуты, значит виноваты роли.
2. Своя ли это нагрузка? Найти свои `rphost` по версии платформы и порту.
3. На большой серверной базе: `1cv8.exe DESIGNER ... /UpdateDBCfg -Server` (реструктуризация силами сервера).
