# ui-driver: агент управляет тонким клиентом 1С через менеджер тестирования

Идея и первая реализация (Linux, Xwayland): Cocky_Idiot, комментарий к статье https://infostart.ru/1c/articles/2815822/.
Здесь вариант для Windows и платформы 8.5, проверенный 19.10.2026 на БП КОРП 3.0.

## Как устроено

- Тестируемый клиент: `1cv8c ENTERPRISE /S <сервер>\<база> /N <тестовый пользователь> /P <пароль> /TESTCLIENT -TPort 1538`.
- Драйвер `ui_Драйвер.epf`: читает файл со скриптом, выполняет его на клиенте через `Выполнить()`, пишет результат в файл и завершает сеанс. В скрипте доступны `Вывести(Текст)` и `Дамп(Объект, Глубина)`.
- Менеджер: тонкий клиент в отдельной пустой файловой базе `tm-base` с ключами `/TESTMANAGER /Execute ui_Драйвер.epf /C "ui=<скрипт>|<выход>"`.
- `ui.ps1 <скрипт.bsl>`: запускает менеджер, ждет выхода, печатает результат.

## Подготовка

1. Собрать обработку из `src` конфигуратором: `1cv8 DESIGNER /F <любая база> /LoadExternalDataProcessorOrReportFromFiles src\ui_Драйвер.xml ui_Драйвер.epf`.
2. Создать пустую файловую базу рядом: `1cv8 CREATEINFOBASE File="<папка>\tm-base"`.
3. Без исключения менеджер повиснет на окне «Предупреждение безопасности». Добавьте в `conf.cfg` платформы строку с регулярным выражением, которое совпадает только со служебной базой, например:
   `DisableUnsafeActionProtection=.*ui-driver.tm-base.*`
   Остальные базы защиту сохраняют.
4. Тестируемый клиент запускать отдельным процессом (например, `Win32_Process.Create`), иначе он закроется вместе с командой, которая его запустила.

## Примеры

`examples/01_dump_windows.bsl` выводит дерево всех окон. `02_open_section_menu.bsl` открывает раздел и выводит меню функций. `03_open_form_dump.bsl` открывает команду из меню и выводит дерево формы. Замените `<Раздел>` и `<Команда>` на свои заголовки.

## Грабли

- У тестируемой формы нет `Закрыть()`, закрывайте окно: `ОкноКП.Закрыть()`.
- `Окно`, `Заголовок`, `Элементы` заняты свойствами формы драйвера, в скриптах берите другие имена.
- Если база ждет обновления ИБ, обычного пользователя в нее не пустят: сначала обновление под администратором.
- Типы элементов не угадывайте: сначала дамп, потом поиск по фактическим именам.
